# Как использовать агентов с Claude Code

## Структура файлов

Скопируй папку `agents/` в корень проекта IronMapper:

```
IronMapper/
├── agents/
│   ├── review-agent.md        ← запускать после каждого этапа
│   ├── test-agent.md          ← запускать после этапа 7
│   └── api-checker-agent.md   ← запускать перед этапом 8
├── src/
├── tests/
└── IronMapper.sln
```

---

## Способ 1 — Прямо в чате Claude Code (самый простой)

После завершения любого этапа просто вставь в чат:

```
Прочитай файл agents/review-agent.md и выполни все проверки описанные там.
```

Claude Code прочитает инструкции агента и выполнит все шаги сам.

---

## Способ 2 — Через команду /task (Claude Code 1.x+)

Открой второй терминал в папке IronMapper и запусти:

```bash
# Review агент (после каждого этапа 1-8)
claude --task agents/review-agent.md

# Test агент (после этапа 7)
claude --task agents/test-agent.md

# API checker (перед этапом 8)
claude --task agents/api-checker-agent.md
```

Агент запустится в отдельном контексте и вернёт отчёт.

---

## Когда запускать каждого агента

| Этап | После выполнения | Агент |
|------|-----------------|-------|
| 0    | Scaffold готов  | review-agent (проверяем структуру) |
| 1    | Атрибуты и API  | review-agent |
| 2    | Source Generator | review-agent (важно! генератор хрупкий) |
| 3    | Fluent API      | review-agent |
| 4    | Продвинутые     | review-agent |
| 5    | DI интеграция   | review-agent |
| 6    | Диагностика     | review-agent |
| 7    | Тесты готовы    | review-agent + **test-agent** |
| 8    | Перед публикацией | **api-checker-agent** |

---

## Что делать с отчётом агента

### Если статус OK:
Переходи к следующему этапу — вставляй следующий PROMPT.

### Если статус ТРЕБУЕТ ИСПРАВЛЕНИЙ:
Вставь в чат Claude Code:

```
Агент проверки нашёл следующие проблемы:
[вставь список проблем из отчёта]

Исправь их все, затем снова запусти dotnet build и dotnet test.
```

### Если критическая проблема (например изоляция Roslyn):
```
СТОП. Агент нашёл критическую проблему:
[описание проблемы]

Это нужно исправить до продолжения. Объясни почему это возникло
и исправь правильно.
```

```
# Терминал 1 — основная работа
cd IronMapper
claude

> [вставляешь PROMPT 2 — Source Generator]
> ... Claude Code работает ...
> Готово, сборка успешна, тесты зелёные.

> Прочитай agents/review-agent.md и выполни все проверки.
> ... агент проверяет ...
> Статус: ГОТОВ К СЛЕДУЮЩЕМУ ЭТАПУ

> [вставляешь PROMPT 3 — Fluent API]
```
