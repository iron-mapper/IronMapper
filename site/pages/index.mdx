## Install

```bash
dotnet add package IronMapper
```

## Quick Start

`Program.cs` of a console app (`dotnet new console`):

<QuickStart />

Mapping code for every type pair is generated into your assembly: `MapTo*` extension methods with explicit property
assignments and no reflection, so the mapping can be read and stepped through in the IDE. Configuration mistakes are
reported at build time as [diagnostics](../../docs/diagnostics.md) at your code.
