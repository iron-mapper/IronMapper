## 2.1.0 — вложенные объекты, конструкторы, корректность (в работе)

- Вложенные объекты маппятся картой своей пары типов, без `ForMember` на каждое свойство; цикл через них —
  предупреждение `IM0004`.
- Несовместимые типы свойств и отсутствующие карты пар — ошибка `IM0002` в вашем коде с code fix вместо ошибок C#
  внутри сгенерированного файла.
- Цели без конструктора без параметров — позиционные record, классы с параметрами конструктора — создаются своим
  конструктором; в профиле можно назвать фабрику (`ConstructWith`) или параметр без свойства (`ForCtorParam`).
- Преобразования значений через карты пар: `CreateMap<Guid, UserId>().ConvertUsing(UserId.From)` применяется к
  каждому свойству и параметру этого типа, nullable поднимается автоматически.
- `IM0023`: nullable-значение для ненулевого члена сообщается на карте, а не как `CS8601`/`CS8604` в сгенерированном
  коде.
- Ещё в 2.1.0: `null` на входе → `null` на выходе под флагом; объём сгенерированного кода; случаи тихой потери данных
  с `required`/`init` и хуками.

Производительность в 2.1.0 не измеряется: цифры на этом сайте — из прогона 2.0.0, и это на них написано.

## 3.0.0

Принятые изменения, которые ждут мажорной версии:

- `null` на входе → `null` на выходе по умолчанию.
- Несопоставленные свойства цели в профилях (`IM0001`) сообщаются по умолчанию.
