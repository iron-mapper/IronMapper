## Установка

```bash
dotnet add package IronMapper
```

## Быстрый старт

`Program.cs` консольного приложения (`dotnet new console`):

<QuickStart />

Код маппинга для каждой пары типов генерируется в вашу сборку: extension-методы `MapTo*` с явными присваиваниями
свойств и без рефлексии, так что маппинг можно прочитать и пройти отладчиком в IDE. Ошибки конфигурации
сообщаются при сборке как [диагностики](../../../docs/diagnostics.ru.md) в вашем коде.
